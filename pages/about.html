About This Website

Mini Deploy Manager is a simple web application designed to help you manage the deployment process of your projects. It provides an easy-to-use interface for adding projects, triggering deployments, and checking the status of your deployments. Built with Spring Boot on the backend and vanilla JavaScript on the frontend, this tool is aimed at developers who want a lightweight solution to manage their project deployments.
